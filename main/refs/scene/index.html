    plotmux.primitives ¶

    Contain the three drawing primitives a backend has to draw.

    The core lowers every mark to Bars, Line or Points (see plotmux.specs.MarkSpec.to_primitives), so a backend only translates these three primitives, and every backend draws the same numbers.

    plotmux.scene ¶

    Contain the scene: the spec of a figure lowered to drawing primitives.

    build_scene owns every decision that changes the numbers on the screen (ranges, bins, steps, stacking, default colors, extents). A backend only translates the three primitives (Bars, Line, Points) and the axes style of an AxesScene into one library, so it cannot draw a different histogram than another backend.

    plotmux.scene.build_scene ¶

    build_scene(spec: PanelSpec) -> AxesScene

    build_scene(spec: GridSpec) -> GridScene

    build_scene(spec: FigureSpec) -> AxesScene | GridScene

    Lower the spec of a figure to a scene.

    It is a pure function of the spec: the same spec gives an equal scene.

    1. The x extent of each panel is resolved (PanelSpec.x_extent).
    2. Each mark is lowered to primitives (MarkSpec.to_primitives), in order.
    3. Each primitive with no color gets the next color of DEFAULT_PALETTE, cycling in drawing order. A primitive with an explicit color does not consume a color, and the first primitive of a single mark gets one too, so the swap of the backend does not change the color.
    4. The legend exists if and only if one primitive has a label.
    5. The categories are collected in order of first appearance.

    Parameters:

    Name Type Description Default
    spec FigureSpec

    The spec of a panel or of a grid.

    		 required

    Returns:

    Type Description
    AxesScene | GridScene

    An AxesScene for a PanelSpec, a GridScene for a GridSpec.
    Example 
    >>> import numpy as np
>>> from plotmux.scene import build_scene
>>> from plotmux.specs import LineSpec, PanelSpec
>>> scene = build_scene(PanelSpec(marks=(LineSpec(x=np.arange(3), y=np.arange(3)),)))
>>> scene.primitives[0].color
(0.12156862745098039, 0.4666666666666667, 0.7058823529411765, 1.0)
