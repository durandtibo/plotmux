    plotmux.utils.range ¶

    Contain utility functions to manage ranges of values.

    plotmux.utils.range.find_range ¶

    find_range(
    values: ndarray,
    xmin: float | str | None = None,
    xmax: float | str | None = None,
) -> tuple[float, float]

    Find a valid range of values.

    Parameters:

    Name Type Description Default
    values ndarray

    The array of values used to compute the quantiles.

    		 required
    xmin float | str | None

    Specifies the lower bound of the range. It can be an explicit value, a quantile string such as "q0.1" (i.e. the 10% quantile, where "q0" is the minimum value and "q1" is the maximum value), or None to use the minimum of values.

    		 None
    xmax float | str | None

    Specifies the upper bound of the range. It can be an explicit value, a quantile string such as "q0.9" (i.e. the 90% quantile, where "q0" is the minimum value and "q1" is the maximum value), or None to use the maximum of values.

    		 None

    Returns:

    Type Description
    tuple[float, float]

    The range of values as a (min, max) tuple. (nan, nan) is returned if values is empty.

    Raises:

    Type Description
    ValueError

    if xmin or xmax is a string that does not have the format "q<quantile>" where <quantile> is a float in the range [0, 1].
    Example 
    >>> import numpy as np
>>> from plotmux.utils import find_range
>>> data = np.arange(101)
>>> find_range(data)
(0, 100)
>>> find_range(data, xmin=5, xmax=50)
(5.0, 50.0)
>>> find_range(data, xmin="q0.1", xmax="q0.9")
(10.0, 90.0)

    plotmux.utils.imports ¶

    Helpers to detect and validate the optional plotting backend dependencies (altair, bokeh, matplotlib, xy).

    For each backend, this package re-exports:

    • is_<backend>_available: indicate if the package is installed.
    • check_<backend>: raise a RuntimeError if the package is not installed.
    • raise_<backend>_missing_error: raise a RuntimeError with a message about the missing package.
    • <backend>_available: a decorator to conditionally execute a function only if the package is installed.

    plotmux.utils.imports.altair_available ¶

    altair_available(fn: F) -> F

    Implement a decorator to execute a function only if altair is installed.

    Parameters:

    Name Type Description Default
    fn F

    The function to conditionally execute.

    		 required

    Returns:

    Type Description
    F

    A wrapper around fn if altair package is installed, otherwise None.
    Example 
    >>> from plotmux.utils.imports import altair_available
>>> @altair_available
... def my_function(n: int = 0) -> int:
...     return 42 + n
...
>>> my_function()
